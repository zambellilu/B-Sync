# B-Sync

Olá, Prof. Fábio! Tudo bem? 

Estou incluindo esse texto como forma de esclarecimento do meu projeto.

Esta é a versão atual do projeto B-Sync. A estrutura principal das páginas e a identidade visual já estão desenvolvidas, mas algumas alterações visuais básicas ainda serão feitas ao longo do desenvolvimento, conforme forem necessárias e também de acordo com a implantação do backend.

Optei por aplicar JavaScript principalmente na tela de login, para melhorar a interação e a navegação entre os diferentes tipos de usuário. No restante do site, mantive a estrutura principalmente em HTML, CSS e Bootstrap nesta etapa, já que na descrição do trabalho estava cobrando apenas a navegação de páginas.
